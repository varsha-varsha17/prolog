# Prolog Family Program

## Description
A simple Family Tree program created using Prolog.

## Facts
Tom is male.
Bob is male.
Pam is female.
Tom and Pam are parents of Bob.

## Rules
father(X,Y) finds the father of Y.
mother(X,Y) finds the mother of Y.

## Sample Queries
father(tom,bob).
mother(pam,bob).
father(X,bob).
mother(X,bob).
