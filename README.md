# Prolog Programming Projects

## Introduction

This repository contains Prolog programs that demonstrate the concepts of logic programming, facts, rules, recursion, searching algorithms, and problem-solving techniques. These programs help understand how logical reasoning can be used to solve different computational problems.

## Objectives

* To understand the fundamentals of Prolog programming.
* To implement facts, rules, and queries.
* To solve problems using logical reasoning.
* To implement search algorithms and basic AI problems.
* To develop problem-solving skills using Prolog.

## Programs Included

### 1. Family Relationship Program

Defines family facts and rules to identify relationships such as father and mother.

### 2. N-Queens Problem

Demonstrates a solution to the N-Queens puzzle using logical constraints.

### 3. Monkey and Banana Problem

Illustrates a classical artificial intelligence problem involving actions and goal achievement.

### 4. Breadth-First Search (BFS)

Explores nodes level by level to find a path through a graph.

### 5. Depth-First Search (DFS)

Explores a graph by following one branch as deeply as possible before backtracking.

### 6. Flatten List

Demonstrates how to flatten a nested list into a single list.

### 7. Water Jug Problem

Uses state transitions to solve a water jug puzzle.

### 8. Personalized Learning Path Recommendation System

Recommends learning topics according to a student's selected career goal. The supported career paths are Banking, SSC, Business, and Technology.

## General Procedure

1. Define the required facts.
2. Create rules to represent the problem logic.
3. Save the program with a `.pl` extension.
4. Load the program into the Prolog interpreter.
5. Execute queries to test the rules.
6. Verify the output.

## How to Run

1. Install SWI-Prolog.

2. Open a terminal in the folder containing the required Prolog file.

3. Run the program using:

   ```bash
   swipl -s filename.pl
   ```

4. Enter the appropriate query at the Prolog prompt.

For the Personalized Learning Path Recommendation System, use:

```bash
swipl -s project/learning_path.pl
```

Then execute:

```prolog
start.
```
